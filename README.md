# Bozor.uz

Стиль и вёрстка сайта не изменены. Добавлена только серверная часть (backend),
без которой товары каждого продавца сохранялись только в его собственном
браузере (localStorage) и никто больше их не видел.

Теперь, после публикации в интернете, всё работает так:
- любой человек может нажать «＋ Продать вещь» и опубликовать товар;
- товар сразу появляется в разделе «🆕 Новые объявления» **у всех** посетителей сайта;
- покупатели могут предлагать свою цену, продавец — принимать/отклонять;
- сообщения и уведомления тоже общие, а не только в одном браузере.

## Что нужно сделать, чтобы это заработало

Сайту нужно небольшое хранилище данных (база), общее для всех посетителей.
Проще всего — бесплатный **Vercel KV** (это часть Vercel, дополнительно
регистрироваться нигде не нужно).

### Шаг 1. Выложите проект на GitHub
1. Создайте пустой репозиторий на github.com.
2. Загрузите туда все файлы из этой папки (`index.html`, папку `api`,
   `package.json`, `README.md`) — просто перетащите их в репозиторий через
   веб-интерфейс GitHub («Add file → Upload files») или через git.

### Шаг 2. Подключите проект к Vercel
1. Зайдите на vercel.com, войдите (можно через GitHub-аккаунт).
2. «Add New… → Project» → выберите ваш репозиторий → «Deploy».
   Настройки по умолчанию менять не нужно.

### Шаг 3. Подключите хранилище (Vercel KV)
1. Откройте ваш проект в Vercel → вкладка **Storage**.
2. Нажмите **Create Database → KV (Redis)** → «Continue» → «Create».
3. На вопрос «Connect to project» выберите ваш проект и нажмите **Connect**.
   Vercel сам добавит нужные переменные окружения (`KV_REST_API_URL`,
   `KV_REST_API_TOKEN` и т.д.) — руками ничего вписывать не нужно.
4. Зайдите во вкладку **Deployments** и сделайте **Redeploy** последнего
   деплоя (чтобы проект подхватил новые переменные окружения).

### Шаг 4. Готово
Откройте адрес вашего сайта (например `https://bozor-uz.vercel.app`).
Теперь товар, добавленный одним человеком, будет виден всем остальным
посетителям — сайт сам обновляет список объявлений каждые 15 секунд, а также
сразу после публикации.

## Важно про безопасность
- Оплата картой на сайте пока не подключена по-настоящему (это и раньше было
  так) — при выборе «Банковская карта» заказ не оформляется, нужно выбрать
  «Наличными при получении» либо подключить настоящего платёжного провайдера.
- В описании товара по-прежнему нельзя указывать номер карты, CVV или пароли —
  это проверяется и на сайте, и теперь дополнительно на сервере.
- У каждого посетителя в браузере автоматически создаётся анонимный
  идентификатор (без имени, почты или пароля), по нему сервер понимает, кто
  автор объявления и кто может его удалить или отвечать на предложения цены.
